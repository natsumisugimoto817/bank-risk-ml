# Explainable ML for Banking

Four connected projects on risk and financial crime, built with interpretability in mind.

| # | Project | Key idea | Status |
|---|---|---|---|
| 1 | Credit scoring with EBM | Glass-box model vs XGBoost; reason codes | In progress |
| 2 | PU learning for fraud | Some fraud is never detected, so "non-fraud" labels are noisy | In progress |
| 3 | Alert triage agent | An LLM agent gathers evidence and writes red flags for analysts | Planned |
| 4 | Model monitoring | Drift detection with PSI and KL divergence | Planned |
